本次源码版本为 1.6.1，基于 1.6.0 的 `1897a82f00b773c9b2bdda48cece6b059330bf2e`。保留上一轮合并的边缘窗口非客户区 guard、统一材质刷新和创建匣默认宽度修复。

## 文件安全与异常恢复

跨盘移动在隐藏源文件前写入 pending_moves 台账。目标提交前仍保留隔离源；复制、发布或 SQLite 提交失败执行逆序补偿。恢复时不能仅凭数据库“有目标行”删除隔离副本：目标丢失会恢复原件，目标内容不匹配会同时保留文件和台账。回滚路径被其他文件占用时不覆盖该文件。

新撤销记录增加流式 SHA-256 内容身份。历史 16 位元数据签名仍按旧语义读取，因此旧记录没有被追溯增强成内容校验。缺失身份的撤销会明确拒绝；这修正了无法确认文件身份仍可能删除文件的行为。剪切拖出令牌同时校验 Windows 卷序号/文件 ID、元数据和内容，令牌只能消费一次，并受五分钟 TTL 限制。

重试领取先落盘，成功后消费原失败项，新失败项由新操作记录承载。若进程在重试期间中断，保留 `retryAttempt` 供核对，不盲目重放可能已经成功的文件动作。文件系统动作和 SQLite 不是同一个原子事务；不可恢复的权限、介质断开或撤销中断仍可能要求用户根据保留路径核对，不能宣称所有系统故障都会自动恢复。错误信息和台账保留实际结果，不以“成功”掩盖补偿失败。

可信交接验证现在把格式错误、重复路径、非法摘要和越界/ADS 路径计入问题；空清单报错。不会再忽略坏行后报告通过。清单读取上限为 8 MiB。

## 本地数据与资源限制

本次没有引入云端解析、遥测或上传。PDF、Office/ODF、图像元数据及清理在本机子进程执行；PDF/Office 全文提取也使用该进程。子进程在读取请求前加入 Windows Job Object：512 MiB 进程提交内存、10 秒 CPU、单进程、父句柄关闭时终止；父进程最多等候 15 秒，解析串行执行。隐私扫描另有 60 秒批次期限、512 MiB 输入预算、目录深度与条目数量限制。超限记录为未完成，不能显示为检查通过。

敏感输入通过匿名管道传递，不为扫描建立明文临时输入文件。清理结果只写入由当前操作独占创建的目标临时目录，成功后无覆盖发布。OCR 仍使用 Windows 自带能力；EFS 和 Windows Hello 行为、机构禁止索引/缩略图/移动策略、便携数据目录与现有 SQLite 迁移入口保持兼容。
