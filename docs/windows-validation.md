# Windows 环境验证清单

这些是需要真实桌面、显示器、文件系统或用户凭据的环境检查，不是 Release 的人工等待步骤。自动 CI 构建和回归测试不会宣称代替它们。

- Windows 10 与 Windows 11：四边浮动条，冷启动、隐藏/显示、设置切换主题与材质、其他窗口获取焦点后再返回，确认没有系统标题栏或细边框残留。
- 100%/125%/150%/200% DPI；跨屏拖动；副屏拔插；任务栏各边；显示器坐标为负；确认浮动条、面板和菜单位置以及点击区域一致。
- 首次向导创建匣与关闭重启后继续；旧配置缺少 panelWidth/material 等字段时完成创建；多匣快速切换时草稿及延迟保存没有串到其他匣。
- 文件复制/移动/链接、拖出复制/剪切、冲突 rename/skip/overwrite、删除/撤销、目录更改、资源管理器 `--stage`；跨盘时拔除介质或制造占用后核对原件/隔离件和台账。使用专门测试文件，不用真实唯一原件。
- 敏感匣：Windows Hello 成功/取消/失败、自动锁定、立即锁定、EFS 成功与不支持的卷、机构禁止索引/缩略图/移动策略。锁定后列表、缩略图和交接入口不能泄露仍显示的数据。
- 应用退出期间有文件操作、解析和保留期清理：观察完成或明确失败后退出，重新启动核对恢复台账。
- 生产证书仅在受信任 Release runner 配置：验证 EXE 和各外层安装包签名；便携 ZIP/MSIX 包内程序哈希一致；无证书时 Notes/manifest 都标记 unsigned。

本轮本地浏览器开发预览已验证设置页布局和文字暂存等界面路径；未完成上列全部原生视觉及硬件组合。请把实际系统版本、缩放率、复现步骤和结果记录在 PR 验证中，不复用上一轮截图作为本轮通过证据。
