# 安心模式与无障碍支持

安心模式是 Community 免费功能，不依赖账号或付费许可。

已提供：

- 100%、125%、150%、200% 整体界面缩放；
- 高对比度、减少透明效果、减少动画；
- 至少 44px 的主要点击目标和强化键盘焦点；
- 文件与文件夹选择器，替代拖拽；
- 资源管理器“发送到 FloePod”和 Ctrl+V 文件粘贴；
- `Alt+1` 至 `Alt+9` 直接打开对应匣并选择文件；
- Enter/Space 选择、Shift+F10/菜单键打开项目菜单、Delete 移出、Ctrl+A 全选；
- 对话框名称、角色、状态和 `aria-live` 错误反馈；
- 移动、批量导出和移出前的清晰操作预览；
- “刚才的操作不对？”一键恢复入口；
- 可关闭悬停自动打开，避免窗口突然出现；
- 简明语言和保留失败选择，避免从头重来。

发布前仍应按照 [release-checklist.md](release-checklist.md) 使用 Narrator、仅键盘、高对比度、200% 缩放和不同 DPI 显示器进行人工验证。自动检查不能替代真实用户测试。
