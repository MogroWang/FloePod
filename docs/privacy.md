# 本地隐私与数据处理说明

FloePod 默认不要求账号，不包含广告或遥测，也不会上传文件名、路径、内容、缩略图、OCR 文本或操作时间线。

## 本机保存的数据

- 暂存文件：位于用户为每个匣选择的文件夹；
- 设置、条目索引、标签、备注和操作时间线：位于本机 SQLite `data.db`；
- 全文和 OCR 索引：仅在用户点击“更新本地索引”后写入本机 SQLite；
- 24 小时撤销文件：位于本机数据目录的 `undo` 子目录，到期后移入系统回收站；
- 日志：本机 `debug.log`，用于用户主动生成诊断包。

## 本地隐私检查

安全导出会提示常见风险：

- 图片 EXIF GPS、作者、设备和软件字段；
- PDF 文档属性和 XMP 元数据；
- Office/OpenDocument 作者、最后编辑者、公司和管理者字段；
- 文件名中的常见身份证号、手机号和邮箱模式；
- 隐藏、临时、备份、零字节、损坏或重复文件。

清理只生成副本，不修改原文件。图片会重新编码，PDF 会移除 Info/XMP 引用，Office/OpenDocument 会重写文档属性。自动检查可能漏报或误报，不代表完全匿名，也不构成医疗、司法、政府或其他行业合规认证。

## 敏感匣

敏感匣使用 Windows EFS 和当前 Windows 用户证书保护磁盘文件，使用 Windows Hello/PIN 控制应用内解锁。FloePod 不保存自制密码、恢复密钥或自行设计的加密算法。

- 不支持 EFS 的卷会拒绝启用；
- 建议机构同时使用 BitLocker 全盘加密和 Windows 账号保护；
- EFS 恢复能力由 Windows 证书备份与机构恢复策略决定；
- 关闭“敏感匣”不会擅自解密已有文件。

正式面向高风险场景宣传前仍应完成独立威胁建模和安全审查。

## 用户主动导出

只有用户明确选择目标目录时，FloePod 才会生成交接包、审计记录、设置备份或诊断包。诊断包默认隐藏本地路径，且不包含文件内容与 OCR 正文。
